🛡️ Scam Detection – URL Risk Checker

Browse Smarter. Stay Protected.

📌 About the Project

Scam Detection is an AI-powered web security platform designed to identify suspicious websites, phishing links, and potentially fraudulent URLs.

The system helps users analyze website URLs and understand potential security risks before visiting unknown websites.

🎯 Problem Statement

Online scams and phishing attacks are increasing rapidly. Many users cannot easily identify fake or malicious websites.

Our project aims to provide a simple and user-friendly platform to help users detect potentially dangerous URLs.

✨ Key Features

- URL Security Scanning
- Suspicious Website Detection
- Phishing URL Analysis
- User-friendly Web Interface
- Risk Assessment of Website URLs

🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Programming Languages: Python, C++, Java
- Database: SQL

⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/broti31cse/Scam-Detection.git

2. Navigate to the project folder

cd Scam-Detection

3. Install dependencies

pip install -r requirements.txt

4. Run the application

python app.py

5. Open in browser

http://127.0.0.1:5000
